
# Titanic Data Cleaning and Visualization

# Project Overview
This project focuses on cleaning and visualizing the Titanic dataset using Python. It involves preparing raw data, handling missing values and exploring patterns through data visualization.

# Objective
To perform data preprocessing and exploratory data analysis (EDA) to improve data quality and understand the dataset.

# Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

# Tasks Performed
- Loaded and explored the Titanic dataset.
- Identified missing values and duplicate records.
- Handled missing values using median and mode.
- Removed unnecessary columns.
- Performed categorical encoding.
- Applied feature scaling.
- Created visualizations to understand the data.

# Outcome
Successfully cleaned and preprocessed the Titanic dataset and performed data visualization to understand its features and patterns.
